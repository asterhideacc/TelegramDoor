# TelegramDoor

**对话有来有往，打扰到此为止。**

部署在自己 Cloudflare 账户里的 Telegram 双向私信机器人，带人机验证、防骚扰规则和中文管理后台。一个机器人对应一位管理员。

访客发消息 → 完成验证 → 重新发送留言 → 管理员收到并引用回复。

**[开始部署](docs/deployment-manual.md) · [使用说明](docs/usage.md) · [更新已有部署](docs/updating.md)**

## 能做什么

- **双向沟通**：文本、图片、视频、语音、文件、贴纸；支持引用回复和部分消息编辑同步。
- **拦截骚扰**：默认算术验证，支持 Turnstile、限频、关键词与链接过滤、封禁和白名单。
- **中文后台**：查看今天、近期和历史的消息与拦截记录，管理访客，直接回复。
- **表情回应**：消息下方的表情按钮，以及管理员 `/react` 命令。
- **自己掌握配置**：机器人、数据库和密码放在自己的账户中，后续通过 GitHub `Sync fork` 更新。

## 部署到 Cloudflare

### 先准备三个值

| 配置             | 填什么                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| `ADMIN_PASSWORD` | 自己设置的后台密码，至少 8 位。                                                                      |
| `BOT_TOKEN`      | 从 Telegram [@BotFather](https://t.me/BotFather) 获取的机器人 Token。                                |
| `OWNER_ID`       | 管理员自己的数字用户 ID，不是用户名或机器人的 ID。[获取方法](docs/deployment-manual.md#开始前准备)。 |

还需要 GitHub 和 Cloudflare 账号。首次在 Cloudflare 创建 D1 数据库并下拉选择绑定即可，**不用复制数据库 ID、修改仓库配置或安装命令行**。Turnstile 暂时不用配置。

### 按一条流程完成

**Fork 项目 → 创建 Worker → 选择 D1 绑定 → 填三个密钥 → 关联 Fork → 连接 Telegram**

👉 **[打开部署教程，从第 1 步开始](docs/deployment-manual.md#1-fork-项目)**

教程包含每一步的点击位置、可复制配置和成功标志。已有部署请看[更新说明](docs/updating.md)，部署失败可按[报错现象查找解决办法](docs/deployment.md#按现象排错)。

### 可以免费用吗？

可以在 Cloudflare 免费额度内运行，无需先购买付费套餐。默认算术验证不需要额外 key；Turnstile 也有免费方案。流量、数据库读写和存储有额度限制，超出会影响服务，具体见[额度说明](docs/usage.md#记录额度与安全)。

## 部署后怎么用

管理员先向机器人发送 `/start`，在后台「防护设置」连接 Telegram。访客完成验证后重新发一条留言，管理员引用收到的消息即可回复。

### 管理命令

| 操作            | 做法                                 |
| --------------- | ------------------------------------ |
| 封禁骚扰者      | 引用其消息，发送 `/ban`。            |
| 临时封禁一天    | 引用其消息，发送 `/ban 1d 广告`。    |
| 解除封禁        | 发送 `/unban 用户ID`，或在后台解除。 |
| 暂停 / 恢复收信 | `/pause` / `/resume`。               |

[查看全部命令、表情回应和后台使用说明](docs/usage.md#管理命令)。

### 使用 Turnstile

默认算术验证无需设置。广告较多时，可在后台切换 Turnstile，再按[配置步骤](docs/usage.md#使用-turnstile)填写两个 key。

### 从其他双向机器人迁移

可以保留自己创建的机器人和用户名。先在 BotFather 撤销旧 Token，再连接 TelegramDoor；具体见[旧机器人迁移教程](docs/migration.md)。

## 使用前了解

- 表情回应通过按钮或 `/react` 操作，**不能自动同步私聊长按消息产生的原生点赞**。
- 相册目前逐条转发，消息删除无法自动同步。一个部署对应一个机器人和一位管理员。
- 验证前的留言不会自动补发；访客通过验证后需要重新发送。验证不能保证拦住所有广告。
- 默认保存文本记录 30 天，可在后台关闭后续文本记录；媒体文件不保存在 Worker。历史记录受保留期限制。

更多说明：[消息能力边界](docs/usage.md#api-能力边界) · [记录、额度与安全](docs/usage.md#记录额度与安全)。当前版本已完成本地自动化检查，真实账户接入请按[验收清单](docs/acceptance.md)测试收发。
